# Banking System in C

A simple **console-based banking system written in C** that simulates basic banking operations such as account login, checking balance, deposits, and withdrawals.

## Features

- 🔐 Account login using account details
- 💰 Check account balance
- 💵 Deposit money
- 💸 Withdraw money
- 👤 Multiple account support
- 🏦 Account information stored using C structures
- 🖥️ Command-line interface

## Technologies Used

- **C**
- Standard C libraries
- Structures
- Arrays
- Conditional statements
- Loops
- Functions
- String handling

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/RehanGarg1/Banking-System-C.git
```

### 2. Enter the project directory

```bash
cd Banking-System-C
```

### 3. Compile the program

Using GCC:

```bash
gcc main.c -o banking
```

### 4. Run the program

On macOS/Linux:

```bash
./banking
```
